# Laboratory Work Management System (C++23)

This repository contains Laboratory Work #1, which combines three distinct tasks into an interactive console application featuring a selection menu.

## 🛠 Implemented Tasks
1. **Task 1 (Variant 14):** Calculation of a complex mathematical formula using the `pow`, `fabs`, `exp`, and `tan` functions from the `<cmath>` library.
2. **Task 2 (Fuel Consumption Calculator):** An interactive calculator for fuel consumption and trip costs based on user input.
3. **Task 3 (Data Type Sizes):** A demonstration of basic data type sizes in bytes (`sizeof`) and fundamental arithmetic operations, utilizing C++23 formatted output (`std::println`).

## 💻 Environment Requirements
* Operating System: **Debian (WSL)**
* Compiler supporting the **C++23** standard (e.g., `g++-13` or newer)

## 🚀 Compilation and Execution

To build the project, run the following command in the terminal:
```bash
g++ -std=c++23 main.cpp -o lab3
```

To run the compiled program:
```bash
./lab3
```
