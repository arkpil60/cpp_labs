# Laboratory Works

A repository for C++ programming laboratory assignments.

## Project Structure
* `first.cpp` — Source code for Lab Assignment No. 3 (Tasks 1–3) featuring an interactive menu.
* `.gitignore` — Configuration to exclude binary files from the repository.

## 🛠 Implemented Tasks
1. **Task 1 (Variant 14):** Calculation of a complex mathematical formula using `<cmath>`.
2. **Task 2 (Fuel Calculator):** Interactive fuel consumption calculator with user input.
3. **Task 3 (Data Type Sizes):** Basic data type sizes (`sizeof`) and C++23 formatted output.

## Compilation and Execution

1. Compile the source code:
```bash
g++ -std=c++23 first.cpp -o lab3
```
2. Run the program:
```bash
./lab3
```
